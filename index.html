Dúvidas

O que mais perguntam.

É um app de namoro?

Não. O estilo de deslizar é parecido, mas aqui o objetivo é um só: achar gente para estudar.

Posso escolher com quem estudar?

Sim. Você vê o perfil, a matéria e os horários antes de decidir. A conversa só abre se os dois derem match.

Funciona para estudo online?

Funciona. Você define se prefere encontro presencial, chamada de vídeo ou os dois.
