#Match Acadêmico

Landing page de apresentação do **Match Acadêmico**, uma proposta de aplicativo que conecta estudantes que estudam a mesma matéria, no mesmo ritmo e nos mesmos horários, usando a mecânica de "deslizar" cartões com foco 100% acadêmico.

🔗 **Acesse o site:** https://sattler777.github.io/Match-Academico/

## Sobre o projeto

Projeto desenvolvido para a **Atividade Curricular de Extensão (ACEX)** do curso de **Análise e Desenvolvimento de Sistemas da UNIPAR – Campus Toledo**.

O aplicativo ainda não foi desenvolvido. Esta página apresenta o conceito, mostra uma prévia de funcionamento e permite que os interessados entrem em uma lista de espera.

## Funcionalidades

- Simulação interativa do app: deslize os cartões de perfis fictícios e veja a tela de "Deu match!"
- Seções explicando como funciona, os recursos e as dúvidas frequentes
- Layout responsivo (computador e celular)
- Lista de espera com envio automático de e-mail de boas-vindas
- Contador de interessados atualizado em tempo real

## Tecnologias

- HTML5, CSS3 e JavaScript
- Figma (prototipação e identidade visual)
- Google Apps Script + Google Sheets (lista de espera, e-mail automático e contador)
- GitHub Pages (hospedagem)
